# Last Catch
**Version 2.0** — 21/08/2026

## Description
*Last Catch* is a generative art piece built with JavaScript and p5.js, my individual contribution to *SEAVENTURE*, a group website promoting SDG 14: Life Below Water. The piece presents a procedurally animated reef ecosystem that quietly and permanently declines over time: an automated claw machine boat fishes the reef with nobody at the controls, and every catch costs the reef's health, a small juvenile fish more than a large mature one. The webpage presents the project's SDG framing alongside the generative piece.

## Usage Notes
- Open the webpage in a browser to view the generative reef and the fishing rig.
- The scene runs and animates on its own; no input is required to watch the reef's health decline over time.
- Click the sound toggle in the top-left corner to turn on the six sound effects (paper-based A1 sounds re-worked, plus new boat, reel, splash and fish-lost sounds); sound starts off by default since browsers block audio until the visitor interacts once.
- This folder is also embedded as `games/tuan-hung` inside the shared *SEAVENTURE* site.

## Installation Instructions
1. Unzip the project folder.
2. Start a local web server in the root directory (e.g. using VS Code's "Live Server" extension, or `python -m http.server`).
3. Open `index.html` in your browser to view the generative artwork and webpage.
4. No external dependencies or plugin installation is required beyond an internet connection to load the p5.js and p5.sound libraries (loaded via CDN).
